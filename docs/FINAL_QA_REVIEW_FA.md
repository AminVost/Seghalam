# گزارش نهایی بازبینی سورس سه‌قلم غذا — ۲۰ اکتبر ۲۰۲۶

## حکم انتشار
**نسخه 0.2.0 یک کاندید آزمایشی سورس است، نه Production یا APK آماده نصب.** چون محتوا از نظر آشپزی تأیید نشده، وابستگی‌های React Native نصب نشده‌اند، Gradle Wrapper / Android SDK در محیط موجود نبود و E2E روی گوشی انجام نشده است، تحویل با عبارت «آماده انتشار» قابل دفاع نیست.

## مبنای بازبینی
- مبنا: `Seghalam_Database_378_Recipes_Expanded_2026-10-20.zip` و سورس فعلی آن.
- نسخه کاتالوگ: ۳۷۸ دستور، ۲۳۶ ماده، ۲۰۴۵ ارتباط ماده–دستور. ۳۷۸ دستور `draft`، صفر `reviewed`.
- حوزه‌ها: خانه، یخچال، دستورها، برنامه غذایی، جزئیات غذا، آشپزی مرحله‌ای، لیست خرید، علاقه‌مندی‌ها، تاریخچه، تنظیمات.
- تست‌های میزبان SQLite یا تحلیل ایستای JSX هرگز معادل تست اجرا و اندازه‌گیری روی Android نیستند.

## شواهد قابل تکرار در این محیط
- `npm run test:all`: پاس؛ شامل ۶۵ تست مستقل، semantic audit و sqlite checks.
- `npm run check:syntax`: چهار فایل کلیدی TypeScript/TSX بدون خطای parser.
- `python scripts/validate_sqlite_schema.py`: پاس.
- `python scripts/test_catalog_v5_migration.py`: پاس، شبیه‌سازی ارتقای v4→v5 در SQLite سیستم میزبان.
- `python scripts/test_session_v6_migration.py`: پاس، شبیه‌سازی v5→v6 با حفظ جلسه و موجودی.
- نسخه standalone کاتالوگ `content/seghalam-catalog.sqlite` با جدول‌های `recipe`، `ingredient` و `recipe_ingredient` نیز جداگانه بررسی شد: ۳۷۸/۲۳۶/۲۰۴۵ و Foreign Key Check بدون خطا. این فایل جایگزین فایل کاربری SQLite برنامه نیست.
- `npm run audit:content`: **عمداً رد می‌شود** زیرا تمام ۳۷۸ دستور بازبینی نشده‌اند؛ این یک گیت ایمنی درست است.
- `npm run typecheck`: **اجرا شد ولی رد شد** چون `react`, `react-native` و تنظیمات/تایپ‌های آن‌ها نصب نیستند؛ بررسی کامل TypeScript ممکن نشد.
- `npm run assemble:debug`: **اجرا شد ولی رد شد** چون Gradle Wrapper موجود نیست؛ APK ساخته نشد.

## کارهای باقی‌مانده برای انتشار واقعی
1. نصب وابستگی‌ها با اینترنت و `scripts/bootstrap-native.ps1` روی ویندوز دارای Android SDK/JDK مناسب؛ کنترل کامل Typecheck و Gradle/Native dependency compatibility.
2. تست E2E تمام فلوها، دیتابیس v5→v6 روی دستگاه، تایمر در background/force-stop، TalkBack و صفحه‌های کوچک/بزرگ و رندر واقعی RTL.
3. تایید تک‌به‌تک دستورها توسط بازبین دارای صلاحیت، منبع اختصاصی، مراحل و مقدار مواد، دماهای ایمن، آلرژن‌ها، تصاویر و حق استفاده. بدون این کار ۳۷۸ پیش‌نویس قابل معرفی به‌عنوان محتوا با کیفیت اثبات‌شده نیستند.
4. افزودن تصویرهای اختصاصی غذا و Dark Mode کامل؛ در نسخه حاضر فقط پوسته روشن بازنگری شده و برای کارت‌ها نماد ساده استفاده شده است.
5. ساخت/امضا/پروفایل Release، الزامات روز کافه‌بازار، اسکرین‌شات واقعی و آزمون پرفورمنس روی گوشی میان‌رده.
6. نیازمندی‌های قبلی هنوز تحقق‌نیافته: تغذیه معتبر، مدل تشخیص عکس، AI محلی، اعلان واقعی تایمر در پس‌زمینه، و برخی تنظیمات شخصی‌سازی.

## دستورهای ادامه در ویندوز
از ریشه پروژه، با Node 22+، Python و Android SDK نصب‌شده:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap-native.ps1
npm run test:all
npm run typecheck
npm run assemble:debug
```

اجرای اسکریپت bootstrap به اینترنت نیاز دارد. خروجی `app-debug.apk` تنها زمانی معتبر است که Gradle واقعاً موفق تمام شود. Release فقط پس از رفع تمام موارد بازبینی محتوا و فعال شدن امضای واقعی ناشر مجاز است.
