# گیت‌های نهایی Production — سه‌قلم غذا

این گزارش درباره وضعیت واقعی سورس در تاریخ ۲۰ اکتبر ۲۰۲۶ است. وجود دستورپخت، صفحه یا فایل Gradle به‌تنهایی به معنای انتشارپذیری نیست.

## انجام‌شده و قابل اثبات در این محیط

- ۱۵۸ ماده استاندارد، ۱۷۲ دستور پیش‌نویس متمایز و حداقل شمارش هر چهار دسته.
- رکوردهای کامل فنی شامل مقدار اولیه، تعداد نفرات، مراحل، زمان اعلامی، داده منشأ و برچسب draft (نه تأیید حسی).
- خروجی SQLite مستقل با ۱۷۲ دستور و ۹۷۷ ارتباط ماده و دستور + Foreign Key بدون خطا.
- import نسخه‌دار محتوای آفلاین به جداول SQLite برنامه، مستقل از موجودی کاربران (کد پیاده‌سازی شده، تست native نه).
- نرمال‌سازی فارسی، نفی و عدم قطعیت، پیشنهاد آفلاین، محاسبه کسری و موجودی، ورود روز شمسی با تبدیل به ISO.
- ۵۱ تست معتبر Domain؛ آزمون schema SQLite، بررسی معنایی پایه، بررسی Syntax چند فایل TS/TSX.
- پرونده مستقل review برای هر دستور به‌همراه SHA-256 محتوا؛ اگر متن و مقدار دستور تغییر کنند، وضعیت بازبینی هنگام تولید دوبارهٔ صف پاک می‌شود. Release gate علاوه بر flag در کد، شواهدِ کاملِ بازبینی را الزامی می‌کند.

## P1 — قابلیت‌ها و کیفیت لازم برای تحقق تمام مشخصات اولیه

- داده تغذیه‌ای معتبر با منشأ USDA، وزن‌های قابل تبدیل و عدم قطعیت؛ کالری ساختگی چاپ نشود.
- جایگزین موادِ وابسته به دستور، قوانین ایمنی و پوشش تبدیل مقدار.
- تایمر و اعلان زمان پخت پایدار در پس‌زمینه با رعایت مجوزهای اندروید.
- تجربه حرفه‌ای طراحی، تصاویر غذا با مجوز تجاری، Light/Dark کامل، فونت/تایپوگرافی استاندارد، TalkBack و کنترل کوچک‌ترین نمایشگرهای معمول.
- سنجش حقیقی مدل AI محلی و مدل تشخیص تصویر فارسی/ایرانی؛ اگر کارایی یا مجوز معتبر ندارد، قابلیت غیرواقعی منتشر نشود.
- تست‌های واقعی JSI SQLite/Android و تست انقطاع فرآیند، کمبود حافظه، Force stop، پروندهٔ دیتابیس خراب.
- ابزار انتشار به‌روزرسانی محتوا با صحت‌سنجی، rollback و حفظ داده کاربران.

## فرمان‌های تکرارپذیر

```powershell
npm run test:all
npm run audit:content
npm run typecheck
PowerShell -ExecutionPolicy Bypass -File .\scripts\bootstrap-native.ps1
```

`test:all` اکنون موفق است. `audit:content` عمداً به علت تأیید نشدن ۱۷۲ دستور خطا می‌دهد؛ `typecheck` به علت نبود dependencies و Android Build به علت نبود Gradle/SDK در این محیط اجرا نشده‌اند. هیچ APK یا امضای نهایی تولید نشده است.

## سیاست امانت‌داری علمی و حقوق نشر

هیچ موردی را با تغییر صوری `contentStatus` به تأییدشده تبدیل نکن. CSV صف بازبینی و `content_hash` فقط ابزار کنترل انضباط فرایند هستند؛ تأیید واقعی مستلزم بررسی و در موارد ضروری طبخ عملی است. URL وب‌سایت حق بازتولید عکس یا متن را نمی‌دهد.
