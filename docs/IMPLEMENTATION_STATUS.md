# وضعیت تازه بازبینی UI/Flow — سورس 0.2.0 (۲۰ اکتبر ۲۰۲۶)

- ۶۵ تست هسته روی Node و مهاجرت میزبان v5→v6 موفق. `npm run test:all` موفق، شامل بررسی ساختار فایل‌های TSX.
- فهرست‌های دستورها، علاقه‌مندی و تاریخچه به FlatList منتقل شدند؛ هیچ FPS یا تصویری روی دستگاه اندازه‌گیری نشده است.
- تعداد نفرات جلسات آشپزی ذخیره می‌شود؛ دوره‌های قدیمی بدون این فیلد به تعداد پیش‌فرض دستور برمی‌گردند.
- جست‌وجوی برنامه غذایی، انتخاب قدیمی را پاک می‌کند و ذخیره غذا خارج از نتایج فعلی را رد می‌کند.
- ذخیره/ویرایش محل نگهداری (یخچال، فریزر، کابینت) پیاده‌سازی شده است.
- محتوا: ۳۷۸ دستور / ۲۳۶ ماده / ۲۰۴۵ پیوند؛ تمام دستورها پیش‌نویس، صفر دستور تأییدشده.
- `npm run audit:content` باید شکست بخورد تا پیش از بازبینی علمی و حقوقی انتشار رخ ندهد.
- Android Native و Full Typecheck هنوز به نصب ابزار و اجرای واقعی نیاز دارند؛ `android/gradlew` در فایل موجود نیست.

جزئیات: `docs/FINAL_QA_REVIEW_FA.md`.

# وضعیت اجرای واقعی سه‌قلم غذا — ۲۰ اکتبر ۲۰۲۶ (ارتقای دیتابیس ۳۷۸ دستور)

معانی وضعیت: `TESTED` تست محلی با شواهد؛ `IMPLEMENTED` سورس نوشته شده بدون تست دستگاه؛ `IN_PROGRESS` تکمیل نشده؛ `BLOCKED` وابسته به محیط یا بازبینی؛ `NOT_STARTED` فاقد اجرای معتبر.

| زیرسامانه | وضعیت | شواهد و کار باقی‌مانده |
|---|---|---|
| موتور پیشنهاد آفلاین | TESTED | ۶۲ تست Node مجموعاً موفق؛ تست روی گوشی انجام نشده |

| تقویم شمسی | TESTED / IMPLEMENTED | Node پاس؛ Hermes Android تأیید نشده |
| فرهنگ مواد | IMPLEMENTED | ۲۳۶ ماده، نام جایگزین؛ صحت برچسب مواد بسته‌بندی و بعضی واحدها مانده |
